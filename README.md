# VLAN-Uygulamasi
Bu çalışma, Cisco Packet Tracer üzerinde temel **VLAN, Access Port, Trunk, Switch IP ve Telnet** yapılandırmalarını kapsayan bir CCNA uygulama labıdır.   Amaç, aynı VLAN’daki cihazların haberleşmesini sağlamak, farklı VLAN’ların izole olduğunu göstermek ve switch yönetimine **Telnet üzerinden erişimi** test etmektir.
